# Project Context: QWind

## Overview
**QWind** is a Qiskit-based Quantum Approximate Optimization Algorithm (QAOA) benchmark for wind-farm layout optimization. 
It is being developed as a hackathon project for **Qollab x IonQ**, under the theme **Quantum Impact**.
The submission deadline is Sunday, Oct 11, 19:00 ET (20:00 Argentina time).

## The Optimization Problem
The problem is modeled as a **Quadratic Unconstrained Binary Optimization (QUBO)** with a cardinality constraint.
- **Objective**: Maximize wind farm power output (minimize energy loss).
- **Variables**: Binary variables $x_i \in \{0, 1\}$ representing the presence of a turbine at cell $i$.
- **Constraint**: Exactly $K$ turbines must be placed out of $N$ candidate cells.
- **Wake Model**: The physical wake loss (interference) between turbines is calculated using the standard **Jensen (1983)** kinematic wake model, integrated over a wind rose (wind direction probabilities).
- **Linear terms ($h_i$)**: Base isolated power of a turbine.
- **Quadratic terms ($J_{ij}$)**: Expected pairwise power loss caused by turbine $i$ waking turbine $j$.
- **Penalty**: A penalty term $\lambda ( \sum x_i - K )^2$ enforces the cardinality constraint.

## Solution Methods
The QAOA quantum approach is benchmarked against classical baselines:
1. **Exact Enumeration** (brute-force).
2. **Simulated Annealing** (SA).
3. **Greedy Local Search** (1-opt swaps).

## Repository Architecture
- `qollab/`: The self-contained core application that will be uploaded to the Qollab platform. It uses only `numpy` and `qiskit` to minimize dependency issues. Entry point: `main.py`.
- `experiments/`: Offline benchmarking scripts that run heavy tasks and rely on external scientific libraries (`scipy`, `matplotlib`, `qiskit-aer`).
- `results/`: The single source of truth for metrics. All data shown on the website or README must strictly come from files here (e.g., `summary.json`). No hand-written claims.
- `web/`: The static presentation website showcasing the project and benchmarking results.

## Fundamental Principles
- **No False Claims**: We do not claim quantum advantage, speedups, or cost savings. If QAOA loses to classical methods, it is reported plainly.
- **Reproducibility**: All experiments use fixed random seeds. Figures and JSON data must be strictly generated by the code.
- **Accessibility**: The website and figures strictly adhere to accessibility standards (alt text, contrast, keyboard navigation).
